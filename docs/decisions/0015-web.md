# ADR 0015 – Web: Qt for WebAssembly (varianta A)

- Stare: acceptat provizoriu (2026-10-26), de reconfirmat cu măsurători din CI și din browser
- Context: Faza 12. Planul cere o decizie între:
  - **A**: aplicația întreagă cu Qt for WebAssembly;
  - **B**: UI web nativ (TypeScript) + `aion_core` în WASM, cu randare WebGL/WebGPU.

## Decizie: A

- **Reutilizare**: tot UI-ul QML, unele, inferența, Document și randarea RHI rămân aceleași. Shaderele au deja
  variantă GLSL 300 es pentru WebGL 2. Varianta B ar însemna rescrierea întregii interfețe și a randării.
- **Risc tehnic**: core-ul rulează deja în WASM, cu teste în Node, din faza prototipului (PR #1).
- **Costuri cunoscute ale lui A**:
  - descărcare inițială mare (Qt + aplicația, ordinul a 15–30 MB comprimat);
  - pornire mai lentă decât o pagină web obișnuită;
  - un singur fir (wasm_singlethread), deci booleenele Manifold mari blochează interfața;
  - fără meniu nativ.
  Sunt acceptabile pentru un modelator 3D (sesiuni lungi).

## Adaptări pentru web

- **Fișiere**: sistemul de fișiere e în memorie. `WebFiles`:
  - deschide prin selectorul browserului (`QFileDialog::getOpenFileContent`) și copiază fișierul în `/tmp/aion`;
  - salvează și exportă în memorie, apoi descarcă (`saveFileContent`).
  Documentul lucrează în continuare cu căi.
- **Autosalvarea**: copia de recuperare se păstrează și în QSettings (persistent în browser), fiindcă fișierele din
  memorie se pierd la reîncărcare.
- **Umbre**: dacă WebGL nu poate randa în R32F (fără EXT_color_buffer_float), umbrele se dezactivează.
- **Build**: preset-ul `wasm-app` înlănțuie vcpkg → `qt.toolchain.cmake` (Qt wasm) → Emscripten. Cere `QT_ROOT_DIR`
  (Qt wasm) și `QT_HOST_PATH` (Qt desktop de aceeași versiune). Qt 6.10 cere Emscripten 4.0.7.
  CI-ul (`wasm-app`) publică pagina ca artefact. Publicarea pe un hosting static (GitHub Pages) e un pas separat,
  la cerere (vezi `.github/workflows/pages.yml`).

## Când revenim asupra deciziei

Dacă pe un laptop obișnuit măsurătorile arată pornire > 10 s sau < 30 fps pe casa din Faza 5, reevaluăm B
(sau un hibrid: UI web + randarea noastră în WASM).
